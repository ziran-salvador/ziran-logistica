# Ziran Logística

Sistema web de logística da Ziran Salvador: exportação (deadlines de draft, VGM e carga), contêineres, transporte, ovação/desova, pré-stacking, armazenagem, relatórios e importação de planilhas (SISTER e bookings).

- **Telas:** `index.html` (publicado pelo GitHub Pages)
- **Login e banco de dados:** Firebase Authentication + Cloud Firestore
- **Configuração:** `firebase-config.js`
- **Regras de segurança:** `firestore.rules` (colar no Firebase › Firestore › Regras)

Instalação completa: veja **PASSO-A-PASSO.md**.
